FIREMONKEY FMX: ANIMATIONS AND TRIGGERS
Quick Reference for Delphi / RAD Studio

PURPOSE
-------
Use this guide to choose an animation component, find a likely PropertyName,
and configure a state-based trigger.

The property names below are common examples, not a promise that every name
works on every FMX control. PropertyName must match a property exposed by the
object being animated. The safest way to discover a valid property is to select
the object in the Form Designer and use the animation/film-strip command next
to the property in the Object Inspector.

1. CHOOSE THE ANIMATION TYPE
-----------------------------
TFloatAnimation
  Use for numeric properties, for example opacity, position, size, scale,
  thickness, margins, and padding values.

TColorAnimation
  Use for color properties, for example Fill.Color or Stroke.Color.

TGradientAnimation
  Use for a gradient property, for example Fill.Gradient, when the target
  object exposes that property.

TBitmapAnimation
  Use for a TBitmap property, for example Fill.Bitmap.Bitmap or
  Stroke.Bitmap.Bitmap, when the target uses a bitmap brush.

TRectAnimation
  Use for TBounds/rectangle-style properties, commonly Margins and Padding.

Important: an animation type must match the type of the property. A
TFloatAnimation is not a general-purpose animation for every kind of value.
In particular, it does not animate Boolean properties or enum values.

2. COMMON PROPERTYNAME VALUES
-----------------------------
A) Numeric properties — TFloatAnimation

  Opacity
  RotationAngle
  RotationCenter.X
  RotationCenter.Y
  Scale.X
  Scale.Y
  Position.X
  Position.Y
  Width
  Height
  Stroke.Thickness
  Margins.Left
  Margins.Top
  Margins.Right
  Margins.Bottom
  Padding.Left
  Padding.Top
  Padding.Right
  Padding.Bottom
  TextSettings.Font.Size  (when this nested path is exposed by the target)

  3D note: Position.Z and Scale.Z are relevant only to objects that expose
  those 3D coordinates. They are not universal properties of 2D controls.

B) Color properties — TColorAnimation

  Fill.Color
  Stroke.Color
  TextSettings.FontColor  (when the target exposes TextSettings)

C) Gradient properties — TGradientAnimation

  Fill.Gradient
  Stroke.Gradient

D) Bitmap properties — TBitmapAnimation

  Fill.Bitmap.Bitmap
  Stroke.Bitmap.Bitmap

  These paths apply only when the target has the corresponding bitmap brush.

E) Rectangle/bounds properties — TRectAnimation

  Margins
  Padding

PROPERTIES THAT ARE NOT FLOAT ANIMATIONS
----------------------------------------
  HitTest                 Boolean property
  TextSettings.HorzAlign  Enum/alignment property
  TextSettings.VertAlign  Enum/alignment property

Do not put these in a TFloatAnimation.PropertyName list. Set them directly in
code or change them in an event handler. Also remember that text settings may
be controlled by the active FMX style; changing a text setting might have no
visible effect until the corresponding StyledSettings option is disabled.

3. TRIGGERS: START AN ANIMATION WHEN A STATE CHANGES
----------------------------------------------------
A trigger is written as:

  PropertyName=value

For example:

  IsMouseOver=true

For animation triggers, the built-in state properties are Boolean. If several
conditions are combined with semicolons, every condition must be true for the
trigger to match. The state must exist on the object being animated; not every
control supports every trigger.

Common triggers available on TControl/TControl3D:

  IsMouseOver=true / false   Pointer is over the control. HitTest must allow
                             mouse interaction for the control to receive it.
  IsDragOver=true / false    A dragged object is over the control.
  IsFocused=true / false     The control has input focus.
  IsVisible=true / false     The control is visible.

Triggers available only on particular control types include:

  IsPressed=true / false     For example, buttons, check boxes, radio buttons,
                             and thumbs.
  IsChecked=true / false     For example, check boxes, radio buttons, and menu
                             items.
  IsSelected=true / false    For example, menu items, tab items, list-box items,
                             and tree-view items.
  IsExpanded=true / false    For example, expanders and tree-view items.

Some controls expose additional Boolean state. Do not assume that IsActive,
IsOpen, IsEnabled, or any other state is a universal animation trigger: verify
that the target exposes that Boolean property and that the state changes at
runtime.

Trigger and TriggerInverse
--------------------------
  Trigger        Starts the animation when the specified condition is met.
  TriggerInverse  Runs the animation in reverse when its inverse condition is
                  met; useful for returning to the original appearance.

For a hover transition, a common pair is:

  Trigger        := 'IsMouseOver=true';
  TriggerInverse := 'IsMouseOver=false';

For example, two conditions can be combined like this:

  Trigger := 'IsMouseOver=true;IsVisible=true';

Both conditions must be true for the trigger to match.

4. EVENTS ARE DIFFERENT FROM TRIGGERS
-------------------------------------
The following are event-handler names, not standard values for the Animation's
Trigger property:

  OnChange
  OnClick
  OnMouseDown
  OnMouseUp
  OnMouseEnter
  OnMouseLeave

To start an animation in response to one of these events, handle the event and
call Start or Stop from the handler. For example:

  procedure TForm1.Button1Click(Sender: TObject);
  begin
    FloatAnimation1.Start;
  end;

Use Trigger/TriggerInverse for supported Boolean states such as hover or focus.
Use event handlers when the action should happen because an event was raised,
for example a click or a value change.

5. DELPHI EXAMPLES
------------------
A) Fade in while the mouse is over a control

  FloatAnimation1.PropertyName := 'Opacity';
  FloatAnimation1.StartValue := 0.0;
  FloatAnimation1.StopValue := 1.0;
  FloatAnimation1.Duration := 0.20;
  FloatAnimation1.Trigger := 'IsMouseOver=true';
  FloatAnimation1.TriggerInverse := 'IsMouseOver=false';

B) Change a shape's fill color on hover

  ColorAnimation1.PropertyName := 'Fill.Color';
  ColorAnimation1.StartValue := $FFFF0000;  // Red (ARGB)
  ColorAnimation1.StopValue := $FF00FF00;   // Green (ARGB)
  ColorAnimation1.Duration := 0.25;
  ColorAnimation1.Trigger := 'IsMouseOver=true';
  ColorAnimation1.TriggerInverse := 'IsMouseOver=false';

C) Animate margins

  RectAnimation1.PropertyName := 'Margins';
  RectAnimation1.StartValue := TRectF.Create(10, 10, 10, 10);
  RectAnimation1.StopValue := TRectF.Create(30, 30, 30, 30);
  RectAnimation1.Duration := 0.25;
  RectAnimation1.Trigger := 'IsMouseOver=true';
  RectAnimation1.TriggerInverse := 'IsMouseOver=false';

These snippets show animation configuration. The animation component must be
attached to the intended target in the usual FMX manner, and that target must
expose the property named in PropertyName. Adjust StartValue/StopValue to the
property's actual type and desired visual result.

6. QUICK TROUBLESHOOTING
-------------------------
- Nothing happens: check the exact PropertyName and confirm the target exposes it.
- The value changes but the appearance does not: check whether the FMX style or
  StyledSettings overrides the text/visual property.
- Hover does not trigger: confirm HitTest and mouse-interaction settings.
- A trigger is ignored: confirm that the target supports that Boolean state.
- A color/rectangle animation fails: confirm that StartValue and StopValue use
  the expected type and that the property matches the animation component.
- An event name such as OnClick does not work in Trigger: start/stop the
  animation from the corresponding event handler instead.
