# Skia Installer Scene

This example connects a SkSL scene to Inno Setup's native installation events. Its progress value is not generated by a demo timer.

## Event mapping

- `CurPageChanged(wpReady)` — ready state before installation.
- `CurStepChanged(ssInstall)` — start of the actual installation phase.
- `CurInstallProgressChanged(CurProgress, MaxProgress)` — real Setup progress while extracting files, creating shortcuts, and writing INI/registry entries. The scene uses `CurProgress / MaxProgress`.
- `CurStepChanged(ssPostInstall)` — main installation operations have finished.
- `CurStepChanged(ssDone)` — successful completion.

The `[Files]` entries copy existing FMXBridge sample assets to `{tmp}\FMXBridgeSkiaScene` and use `deleteafterinstall`. They provide actual Setup work so the progress callback can be observed without installing application files on the machine.

## Important scope

`CurInstallProgressChanged` reports the progress of Inno Setup's own installation operations. It does not provide a separate percentage for each archive, custom extraction routine, or child redistributable installer launched with `Exec`. Those operations need explicit progress notifications from the code that performs them. This example deliberately does not invent percentages for external processes.

`ssDone` is the success state. The general `DeinitializeSetup` event is also called when Setup exits early, so it is not treated as proof of success. The example does not guess whether an incomplete run was cancelled or failed.

## Files

- `Example_SkInstallerScene.iss`
- `Files/Shaders/installer-scene.sksl`
- Existing sample payload: two fonts, one SVG and one Lottie JSON asset.

## Build

The same FMXBridge and Skia4Delphi DLL preparation as the other scripts in `Examples/Skia/Modules/README.md` is required. The sample targets x64 by default; change `SetupArchitecture` to `x86` to test the 32-bit pair.

Use Inno Setup 6.5.4 or newer for this example. The official revision history lists a runtime-error fix for `CurInstallProgressChanged` in 6.5.4.
